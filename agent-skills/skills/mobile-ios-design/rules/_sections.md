# Sections

This file defines all sections, their ordering, impact levels, and descriptions.

---

## 1. Visual Hierarchy (visual)

**Impact:** CRITICAL  
**Description:** Principles for creating clear visual hierarchy using semantic colors, typography scale, and consistent spacing. Ensures UI communicates importance and structure effectively.

## 2. Layout Patterns (layout)

**Impact:** HIGH  
**Description:** Safe area handling, adaptive grids, scroll behavior, and responsive design patterns for building layouts that work across device sizes.

## 3. Data Visualization (dataviz)

**Impact:** HIGH  
**Description:** Patterns for displaying multi-dimensional data (radar charts, progress rings, stat cards) in a clear, accessible, and visually appealing way.

## 4. Card Design (card)

**Impact:** HIGH  
**Description:** Consistent card patterns using flat pastel backgrounds, subtle borders, and appropriate information density — avoiding glassmorphism for clarity.

## 5. Accessibility (a11y)

**Impact:** MEDIUM  
**Description:** Ensuring all UI components are accessible with proper semantic labels, sufficient touch targets, and adequate color contrast.

## 6. Animation (animation)

**Impact:** MEDIUM  
**Description:** Meaningful, performant animations that convey state changes without impacting scroll performance or user experience.
