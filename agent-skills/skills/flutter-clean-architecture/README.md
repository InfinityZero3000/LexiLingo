# Flutter Clean Architecture

Clean Architecture patterns for LexiLingo Flutter features. Covers Domain/Data/Presentation layer separation with Provider state management.

## When to Use

Apply for every new feature: Notifications, Level System, User Stats, Course Categories.

## Key Rules

| Rule | Impact |
|------|--------|
| `domain-entity-pattern` | CRITICAL |
| `domain-repository-interface` | CRITICAL |
| `data-model-fromjson` | HIGH |
| `data-repository-impl` | HIGH |
| `presentation-provider-pattern` | HIGH |
