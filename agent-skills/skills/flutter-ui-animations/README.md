# Flutter UI Animations

Animation patterns for LexiLingo Flutter app: shimmer skeletons, staggered list entry, Hero transitions, and Level-Up celebration.

## Quick Reference

| Rule | Impact | When to Use |
|------|--------|-------------|
| `loading-shimmer` | HIGH | Any screen with async data load |
| `list-staggered-entry` | HIGH | Home, Notifications list on load |
| `nav-hero-course-card` | HIGH | Course card → detail navigation |
| `celebrate-level-up-dialog` | MEDIUM | XP threshold crossed |

See [AGENTS.md](./AGENTS.md) for full guide.
